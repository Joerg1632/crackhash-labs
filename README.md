# CrackHash

Учебный проект для реализации распределённой системы по взлому хэшей (MD5) через простой перебор словаря (brute-force).

## Предисловие

Система состоит из двух компонентов:

- **Менеджер (Manager)** – принимает запросы от клиента с хэшем и максимальной длиной слова, делит задачу на диапазоны и отправляет их воркерам.
- **Воркеры (Worker)** – перебирают слова в заданном диапазоне, вычисляют хэши и возвращают совпавшие результаты менеджеру.

---

## Стек технологий

- ASP.NET Core Web API (C#)
- Docker / Docker Compose
- PostgreSQL (для хранения состояния запросов)
- (Опционально для второй лабораторной) RabbitMQ для очередей сообщений

---

## REST API

### Менеджер

**POST** `/api/hash/crack` – создать запрос на взлом хэша

```json
{
  "hash": "e2fc714c4727ee9395f324cd2e7f331f",
  "maxLength": 4
}
```

Response
```json
{
  "requestId": "730a04e6-4de9-41f9-9d5b-53b88b17afac"
}
```

**GET** `/api/hash/status?requestId={requestId}` – получить статус и результат

Если задача ещё выполняется:

```json
{
  "status": "IN_PROGRESS",
  "data": null
}
```

Если задача выполнена:

```json
{
  "status": "READY",
  "data": ["abcd"]
}
```

## Воркеры

- **POST** `/internal/api/worker/hash/crack/task` – получение задачи от менеджера (JSON или XML).
- **PATCH** `/internal/api/manager/hash/crack/request` – отправка результатов менеджеру.

---

## Алфавит

Используется ограниченный набор символов:

- строчные латинские буквы (`a-z`)
- цифры (`0-9`)

Генерация комбинаций реализуется через потоковый итератор, чтобы не держать в памяти весь диапазон слов.

## Запуск через Docker Compose

1. Склонировать репозиторий:

```bash
git clone <repo-url>
cd CrackHash
```

2. Запустить контейнеры:
```bash
docker-compose up --build
```

3. Доступ:

- Менеджер: http://localhost:5000

- Воркеры: доступны внутри сети Docker Compose, связываются с менеджером по сервисным именам.
